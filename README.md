# TaskFlow

A modern Trello-inspired project management application built with React, TypeScript, and Tailwind CSS.

## Features

* Create and manage boards
* Organize tasks into columns
* Drag and drop task management
* Responsive design
* Modern UI
* User authentication (planned)
* Team collaboration (planned)

## Tech Stack

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS

### Future Backend

* Node.js
* Express.js
* PostgreSQL
* Prisma

## Installation

```bash
npm install
npm run dev
```
