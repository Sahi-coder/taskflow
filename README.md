# TaskFlow — Trello-like Task Management App

TaskFlow is a modern, responsive project management application inspired by Trello.  
It helps users organize tasks visually using drag-and-drop Kanban boards.

---

## 🚀 Live Demo

🌐 https://taskflow-qs66z57k1-sahi-s-projects2.vercel.app/

## ✨ Features

- 🗂️ Create and manage boards
- 📌 Organize tasks into columns (To Do, In Progress, Done)
- 🔄 Drag and drop task management
- 📝 Add, edit, and delete tasks
- 📅 Due date support for tasks
- ⚡ Fast and responsive UI
- 📱 Fully responsive design (mobile + desktop)
- 🎯 Clean and modern Kanban-style layout
- 🔐 (Future) Authentication system
- 👥 (Future) Team collaboration features

## ⚙️ Installation & Setup

```bash
git clone https://github.com/Sahi-coder/taskflow.git
cd taskflow
npm install

Create .env file:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

Run project:

npm run dev
